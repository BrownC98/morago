사용자 지정 번역 서비스: 요청 값 JSON 편집

사람의 요구: 사용자 지정 번역 서버에 보내는 요청(OpenAI chat completions 규격)에 넣을 값을 JSON으로 자유롭게 적는다. [추론 강도] 선택 칸은 없앤다. 모델도 JSON에서 정한다.
